## 📌 Projetos

### 🩺 ClinWave — SaaS clínico com assistente de IA
> *Código fechado — posso mostrar em uma conversa.*
>
> Plataforma multi-tenant para clínicas, com agenda, prontuário eletrônico e escalas clínicas.
> Nasceu como um bot de agendamento no WhatsApp, com redução estimada de 80% no tempo de agendamento.
> API REST em Flask sobre PostgreSQL com Row-Level Security por clínica, webhooks da WhatsApp Cloud API
> com validação HMAC, pagamentos via Mercado Pago e a assistente **Sofia** (Google Gemini), que envia e
> coleta escalas clínicas pelo WhatsApp. Deploy com Docker no Fly.io e Railway.
>
> **Stack:** Python · Flask · PostgreSQL · Google Gemini · Docker · React · pytest

### 🛰️ CarpaLink — internet temporária via satélite
> *Negócio próprio.*
>
> Locação de Starlink para eventos, viagens, propriedades rurais e obras no DF, GO e MG.
> Desenvolvi o site institucional, com captação de leads integrada ao WhatsApp e SEO técnico.

### ⚙️ [mini-c-compiler](https://github.com/joaoarchives/mini-c-compiler)
> Interpretador de uma linguagem mínima em C: análise léxica, análise sintática com construção de AST,
> análise semântica com tabela de símbolos e execução. Trabalho de Compiladores, com o operador `%`
> implementado e casos de teste documentados.
>
> **Stack:** C

### 🔍 [MiniLexer_MiniC](https://github.com/joaoarchives/MiniLexer_MiniC)
> Analisador léxico da linguagem MiniC, em C puro: lê o código-fonte caractere a caractere e reporta
> linha, coluna, categoria e lexema de cada token, contabilizando erros léxicos.
>
> **Stack:** C

### 🍕 [Delivery-de-Pizzas](https://github.com/joaoarchives/Delivery-de-Pizzas)
> Sistema de pedidos de pizzaria que usa árvore binária de busca para ordenar as entregas por tempo,
> com persistência em SQLite e interface web.
>
> **Stack:** Python · Flask · SQLite
